# YouTube Auto Downloader (Audio & Video)

Simple Python automation to download YouTube audio or video automatically when you copy a YouTube link.

- Audio files → saved in `Desktop/My_Audios`
- Video files → saved in `Desktop/My_Videos`

## Install required libraries

Copy and run this command in your terminal:

```bash
pip install yt-dlp pyperclip plyer
```


## Run Audio downloader

```bash
python audio_downloader.py
```

Then just:

1. Copy any YouTube video URL
2. Download starts automatically
3. Audio will be saved in:

```
Desktop/My_Audios
```

## Run Video downloader

```bash
python video_downloader.py
```

Then just:

1. Copy any YouTube video URL
2. Download starts automatically
3. Video will be saved in:

```
Desktop/My_Videos
```
